# 📚 AI-Based E-Learning Application

An AI-powered e-learning platform that allows users to generate personalized learning paths using simple text prompts. The application creates structured courses, learning points, and interactive content, making education flexible, engaging, and learner-centered.

Users can explore multiple courses, track progress, and continuously assess their understanding through AI-generated quizzes and activities.

# 🚀 Key Features

AI Course Generation
Generate learning points, topics, and complete courses from user prompts using Generative AI.

Personalized Learning Paths
Adaptive content tailored to user interests, pace, and progress.

Interactive Learning Modules
Includes quizzes, flashcards, and question–answer sections for better retention.

Progress Tracking
Monitor completed topics, quiz performance, and overall learning progress.

Multi-Course Access
Users can create, save, and switch between multiple courses easily.

Continuous Assessment
Regular quizzes and AI-driven feedback to reinforce learning.

Responsive & User-Friendly UI
Optimized for smooth and intuitive learning across devices.

# 🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript,ReactNative

Backend: Firebase-Firestore

AI & NLP: Google Gemini AI, Natural Language Processing (NLP)

# 🎯 Use Case

This application is ideal for:

Students seeking personalized learning experiences

Self-learners exploring new topics

Educators creating adaptive learning content
